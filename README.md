# CARZA V2
Multi-page front-end prototype.

Files:
- index.html — home
- cars.html — marketplace
- dealers.html — dealer directory
- dealer-dashboard.html — dealer portal prototype
- styles.css — design/responsive layout
- app.js — demo vehicle/dealer data and interactions

Upload all files to the repository root. Enable GitHub Pages from Settings → Pages → main → root.

This is still a prototype: real database, authentication, moderation, secure vehicle uploads and payments are not connected yet.
